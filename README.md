# 📇 Simple Contacts

A full-stack web application built with **Flask** for the backend and **React** for the frontend. This project demonstrates CRUD (Create, Read, Update, Delete) operations on a contact list with persistent storage. It was built as a hands-on project to explore Flask and React integration.

---

## 🚀 Features

- Create new contacts with name, email, and phone
- View all stored contacts
- Update existing contacts
- Delete contacts
- Persistent data storage using Flask backend

---

## 🛠️ Tech Stack

### Frontend
- React
- JavaScript (ES6+)
- CSS

### Backend
- Python
- Flask
- Flask-CORS
